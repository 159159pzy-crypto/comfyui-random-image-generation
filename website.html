一张能力地图

从提示词到收藏，生成是一条循环。点击节点查看细节。

01 / INPUT

提示词池

角色、服装、姿势、背景、表情五类词条各自成池，每一类独立设置随机 / 固定 / 关闭，支持池内搜索与分类筛选。

  • 五类池独立开关与随机策略
  • 词条搜索与分类筛选
  • 与风格预设联动，一键换整套组合
Features

细节，也被照顾到

批量生成与队列

一键抽卡，运行中追加批次自动排队，进度实时预览。

LoRA 管理

可视化卡片选择器，触发词管理与强度调节。

高清修复

独立开关 + 放大模型 + 1–1000% 缩放比例。

四个 Detailer

手部、NSFW、面部、眼睛独立开关。

风格预设

模型 + LoRA + 尺寸 + 步数 + 修复整套存取。

收藏树

Finder 式任意层级分组，批量收藏跨页选择。

Workflow

三步一轮

01STEP 01

配置提示词

词池组合 + LoRA + 预设，设定批量数量。

02STEP 02

批量生成

实时预览采样进度，追加批次自动排队。

03STEP 03

管理收藏

拖入收藏树，或按原种子 / 换种子 / 按类别重抽。
