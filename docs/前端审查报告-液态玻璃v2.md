# Anima Studio 前端审查报告(液态玻璃 v2)

日期:2026-07-26 · 审查对象:`static/index.html`(25.4KB)、`static/styles.css`(55.3KB)、`static/app.js`(103.4KB)

**方法**:两路独立深读(JS 一路、HTML/CSS 一路)+ 无头 Chrome 实测(搭真实结构的 API 桩,桌面 1440×900 / 移动 390×844,亮暗双主题)+ axe-core 无障碍扫描。标注 **[实测复现]** 的条目均在真实渲染中确认,非纸面推断。

## 总体评价

底子相当扎实。JS 侧:统一的 `ui` 元素表加启动期缺件自检,正好对冲了视觉重构改 DOM 的最大风险;`escapeHtml` 在几十处 innerHTML 拼接中覆盖率接近 100%;`loadPool/loadHistory` 有 requestId 竞态守卫;轮询有 hidden 判断与空闲降频。CSS 侧:亮暗变量层完全对称;头部内联脚本防主题闪烁;抽屉的 inert + 焦点转移/归还是教科书式的;z-index 阶梯自洽;reduced-motion / reduced-transparency / prefers-contrast 三套系统偏好都有响应。在正确的接口数据下整页零 JS 报错。

主要短板:好模式执行不一致(守卫、编码、try/catch 各有漏网),以及 backdrop-filter 的「面积×数量」失控。

## 🔴 必须修(6 项)

**1. Esc 会把弹窗和抽屉一起关掉** — `app.js` L2448 **[实测复现]**
document 级 Escape 监听只判断抽屉,不判断是否有 `<dialog>` 开着;在池抽屉里打开任意弹窗后按 Esc,两层同时关闭。
修法:监听器句首加 `if (document.querySelector("dialog[open]")) return;`(dialog 自身的 Esc 由浏览器处理)。

**2. 批次数量改完不存草稿** — `app.js` L2215 一带 + `index.html` L148 **[实测复现]**
`#count` 移到表单外靠 `form` 属性关联后,input 事件不再冒泡进表单的委托监听;实测改成 77 后草稿里仍是旧值,直到改动其他任意字段才被捎带保存,只改数量就刷新会丢。
修法:给 `ui.count` 单独绑 `input → schedulePersist`。

**3. 空 facet 时抽屉侧栏渲染出字面 "nullnull"** — `app.js` L1222-1229 **[实测复现,见截图]**
`sidebarSection()` 空数据返回 `null`,`nav.append(null)` 插入文本 "null";服装池(无收藏无分组时)侧栏直接可见。
修法:`nav.append(...[...].filter(Boolean))`,或让该函数返回空 fragment。

**4. 作品卡逐卡 `backdrop-filter: blur(32px)`** — `styles.css` L478 **[实测确认]**
计算样式确认每张 `.image-card` 都建了独立模糊层;卡片在滚动容器里、底下只是页面底色,模糊几乎不可见却按张数付 GPU 成本,图一多必掉帧。
修法:删掉该行,保留半透明 `--surface` 背景即可,视觉几乎无差。

**5. 移动端批次输入框丢失可访问名称** — `styles.css` L746 **[axe: critical]**
小屏 `.quantity-field span { display:none }` 把 `#count` 唯一的 label 文本移出了可访问性树,axe 判 critical。
修法:label 文本改 sr-only 隐藏(`position:absolute; clip-path:inset(50%)` 等),或给 input 加 `aria-label="批次数量"`。

**6. 底部指令台没留 safe-area** — `styles.css` L207 / L725,`index.html` L5
fixed 指令台 `bottom: 18px/12px`,在 iPhone 全面屏会压住 Home 条手势区。
修法:`bottom: calc(12px + env(safe-area-inset-bottom))`,并在 viewport meta 加 `viewport-fit=cover`。

## 🟡 建议修

### JS:竞态与网络健壮性

**7. 开始生成 vs 轮询的乱序响应** — `app.js` L737-752 / L2203-2214
POST 新批次后,一条更早发出的 `/api/batches/current` 旧响应可把 UI 打回「批次完成」并重新启用开始键(空闲降频下窗口最长约 5 秒),期间可二次提交。修法:仿 `loadPool` 的自增 requestId 丢弃乱序响应。

**8. `request()` 无超时,轮询不去重** — `app.js` L295-308 / L2483
后端挂起时每 1.2s/5s 叠加新 fetch 无上限;网络异常的英文 `Failed to fetch` 直接进 toast。修法:`AbortSignal.timeout(10000)`,捕获 TypeError 映射为「无法连接服务器」。

**9. 收藏/自定义分组的抽屉切换竞态** — `app.js` L845-864
`loadFavorites` await 后不校验 section 是否仍是当前分区,快速关开不同池时旧响应覆盖新分区数据,收藏标记错乱。修法:响应落地前 `if (section !== activeSection) return`。

**10. 池翻页失败不回滚页码** — `app.js` L2300-2307
`poolPrev/Next` 先改 `poolPage` 再请求,失败后状态与界面脱节,下次翻页跳页;`loadPool` 的 catch 也缺 requestId 守卫(`loadHistory` L781 有,学它)。

**11. LoRA 弹窗按 Enter 直接关闭** — `index.html` L300 **[实测复现]**
`method="dialog"` 表单里 `#loraSearch` 是唯一文本控件,Enter 触发隐式提交关窗,搜索时按 Enter 是高频误触。修法:该 form 绑 `submit` 并 `preventDefault`。

**12. 姿势冲突检测漏报** — `app.js` L1302
依赖 `poseItemCache`,刷新后恢复的草稿选中项不在缓存里被静默跳过,直到翻到对应页才补上。修法:对缺失 id 调 selection 版查询接口补齐。

### CSS/HTML:视觉与可访问性

**13. sticky 同款隐患再现** — `styles.css` L107
`main, .mobile-tabs { position:relative }` 与 L728 的 sticky 同优先级、纯靠源码顺序险胜——正是上次顶栏失去 sticky 的成因。修法:L107 移除 `.mobile-tabs`。

**14. 暗色下高对比偏好失效** — `styles.css` L804
`prefers-contrast` 只在 `:root`(0,1,0)覆写,输给 `html[data-theme="dark"]`(0,1,1)。修法:选择器改成 `:root, html[data-theme]`。

**15. theme-color 首屏不同步** — `index.html` L6
meta 固定浅色 `#f5f5f7`,暗色用户首屏浏览器框仍是浅色(app.js 只在手动切换时改)。修法:头部内联主题脚本里一并写 meta。

**16. reduced-transparency 名单不全** — `styles.css` L798-801
漏了 `.image-card`、`.drawer-backdrop`、`dialog::backdrop`。修法:补进同一规则并给实色背景。

**17. 非法 font 简写被整条丢弃** — `styles.css` L375 **[实测确认]**
`font: normal 15px/1 inherit`(CSS-wide 关键字不能进简写)静默失效,折叠区 "+" 图标实际渲染 13.5px/字重 620。修法:拆成独立属性 `font-size:15px; line-height:1; font-weight:400;`。

**18. 隐藏原生控件后键盘焦点不可见** — `styles.css` L568 / L623
池卡片复选框 0×0、文件输入 1×1,Tab 到它们时无任何焦点指示。修法:`.pool-item:has(input:focus-visible) { outline:3px solid var(--accent) }`,file-button 同理。

**19. 无 backdrop-filter 环境没有兜底** — `styles.css` L119
58% 白的 `--chrome` 直接叠内容,文字糊底。修法:`@supports not (backdrop-filter:blur(1px)) { .glass,.topbar,.command-deck,dialog,#toast { background:var(--chrome-solid) } }`。

**20. 触控目标偏小 + 小字对比度不足** — `styles.css` L578/L429/L404,L392/L427/L642 **[axe: serious]**
item-tools 24px、preset-actions 27px 等远低于 44px 建议值;8.5-9px 中文小字低于可读下限,`--text-tertiary #8e8e93` 在浅色玻璃上约 3.5:1 不达 AA(axe 在卡片说明文字上报 serious)。修法:操作件提到 ≥32px 并用 padding 扩热区;小字 ≥10px,tertiary 加深一档。

**21. 移动端标签页缺状态语义** — `index.html` L35
只切 `.active` 视觉类,读屏不知当前视图。修法:JS 切换时同步 `aria-pressed`(或改 tablist/tab + `aria-selected`)。

**22. 关闭态抽屉常驻合成层** — `styles.css` L498
仅 transform 移出视口,fixed + blur(32px) 层一直挂着空耗 GPU。修法:非 `.open` 时补 `visibility:hidden`(transition 延迟 visibility 避免打断动画)。
