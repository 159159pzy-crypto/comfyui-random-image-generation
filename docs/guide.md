# 使用指南

## 1. 源码安装与启动

项目在独立 Python 虚拟环境运行，要求 Python 3.11+。Windows 可使用根目录的 `Install.ps1` 和 `Start.ps1`；也可以手动完成相同操作：

```powershell
Set-Location F:\animarandom
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe run.py
```

需要开发工具时，将安装命令改为 `-m pip install -e ".[dev]"`。Node.js 22+ 只用于 `scripts/check.py` 和前端测试，不参与 WebUI 服务运行。

先单独启动 ComfyUI，再启动 WebUI。默认 WebUI 地址为 `http://127.0.0.1:8191`，ComfyUI 地址为 `http://127.0.0.1:8188`。`Start.cmd` 是调用 PowerShell 的源码启动入口，没有后台托盘或 EXE 服务。按 Ctrl+C 或关闭启动终端停止 WebUI。正在执行和等待中的批次属于当前服务进程；重启不会自动续跑队列。

### 命令行参数

`Start.ps1`、`Start.cmd` 会把参数传给 `run.py`。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `--host` | `127.0.0.1` | 只允许 `127.0.0.1`、`localhost`、`::1` |
| `--port` | `8191` | WebUI 的本机端口 |
| `--comfy-url` | `http://127.0.0.1:8188` | 本机 ComfyUI 的 HTTP 地址，可用 localhost 或 IPv6 回环地址 |
| `--anima-tools-dir` | 自动发现 | Anima Tools 插件根目录，目录中应包含 `js/` |
| `--data-dir` | 项目 `data/` | 本项目个人数据和日志目录；建议使用绝对路径 |
| `--resource-paths` | 无 | UTF-8 JSON 模型相对路径映射文件，见下文 |
| `--no-browser` | 关闭 | 不自动打开浏览器，手动访问 WebUI 地址 |

例如仅启动服务、不打开浏览器：

```powershell
.\Start.ps1 --port 8193 --data-dir "F:\AnimaData" --no-browser
```

IPv6 回环示例：

```powershell
.\Start.ps1 --host ::1 --comfy-url "http://[::1]:8188" --no-browser
```

手动访问 `http://[::1]:8191`。此时 ComfyUI 也必须监听该回环地址。WebUI 仅提供本机单用户访问，不提供局域网或公网部署模式。ComfyUI 地址拒绝远程主机、HTTPS、凭据、查询参数和片段。

## 2. 基础词库发现

人物、服装、姿势、背景分别读取 Anima Tools 的以下文件：

```text
js/character_data.js
js/clothing_data.js
js/pose_data.js
js/background_data.js
```

表情词库由本项目内置。中文名称补充表也随项目提供。自定义词条和收藏存入本项目数据目录，不写回这些基础文件。

发现优先级为：`--anima-tools-dir` → `ANIMA_TOOLS_DIR` 环境变量 → `COMFYUI_ANIMA_TOOLS` 环境变量 → 自动扫描。自动扫描只检查项目相邻的 `comfyui/custom_nodes`、项目自己的 `custom_nodes`、项目父目录的 `custom_nodes`，不搜索整个磁盘。

显式指定的目录无效时会报告缺失文件，不会悄悄使用其他安装。发现多个有效目录时需要明确指定其中一个。修复路径或更新基础词库后重启 WebUI。

## 3. 模型选择与路径映射

默认资源名称如下，实际加载以 ComfyUI 返回的资源清单为准：

| 用途 | 默认名称 |
| --- | --- |
| Anima 主模型 | `anima-base-v1.0.safetensors` |
| 文本编码器 | `qwen_3_06b_base.safetensors` |
| VAE | `qwen_image_vae.safetensors` |
| 可选像素高清模型 | `4x_foolhardy_Remacri.pth` |
| 可选 SeedVR2 模型 | `seedvr2_3b_int8_convrot.safetensors` |
| 可选 SeedVR2 VAE | `ema_vae_fp16.safetensors` |

主模型可在界面中选择；编码器和 VAE 按 Anima 配置绑定。所有启用的资源必须存在于对应 ComfyUI 加载器清单中。

若资源位于子目录或使用其他兼容文件名，可创建 UTF-8 JSON 文件，例如 `resource-paths.json`：

```json
{
  "anima-base-v1.0.safetensors": "Anima/anima-base-v1.0.safetensors",
  "qwen_3_06b_base.safetensors": "Anima/qwen_3_06b_base.safetensors",
  "qwen_image_vae.safetensors": "Anima/qwen_image_vae.safetensors",
  "4x_foolhardy_Remacri.pth": "ESRGAN/4x_foolhardy_Remacri.pth"
}
```

```powershell
.\Start.ps1 --resource-paths .\resource-paths.json
```

键和值都是资源名称字符串，值必须与相应加载器显示的相对路径一致。路径相对于对应模型根目录，不包含盘符、绝对路径或 `..`；建议使用 `/`，不要添加本地 `models/` 根目录前缀。映射只改变资源引用，不复制文件，也不会把不兼容模型转换成 Anima。

新任务会优先匹配明确的现有路径；只有未明确到子目录的名称，才允许唯一同名文件匹配。多个同名文件需要明确指定。历史保存已解析的路径；复现时不会因为映射变化而自动换成别处的同名模型。旧资源移动或删除后，先处理界面报告的缺失资源。

“模型 / LoRA 分类”只读 ComfyUI 与 LoRA Manager 的分类信息。它不修改共享模型资料。分类依赖和节点要求见 [依赖说明](dependencies.md)。

## 4. 五池随机与本地整理

每个维度可关闭、使用固定词或从候选池随机抽取。候选池支持选择条目、排除条目、收藏和自定义词条；按界面的候选数量和抽取数量确认实际范围。人物可设置描述详细程度；人数、画师、质量词、额外词和负面词另行配置。

自定义词支持单条编辑、分组，以及 JSON/CSV 批量导入。使用当前维度提供的模板，选择文件后先检查预览和错误，再确认导入。收藏分组和自定义分组属于本地数据；删除对话框会明确区分仅删分组、独占条目与关联内容。

“高级提示词 → 管理规范与替换”提供本地 Tag 格式化和自定义替换，可分别作用于正向、负向和 LoRA 触发词。编辑结束后按启用的规则处理，界面提供上次规范的撤销入口。该功能在本地执行，不调用 AI 助手或云端模型。

LoRA 区支持快速添加、启停、权重、触发词管理，以及展开后的搜索、筛选、预览、本地星标、标签、备注、分组和人物绑定。绑定人物被抽中时，按绑定配置自动启用对应 LoRA。手动配置与自动绑定的实际运行信息随历史保存。

LoRA 使用次数仅统计当前本地历史中成功保存图片所启用的 LoRA，每张图片对同一 LoRA 计一次；删除相关历史记录后次数会下降，不继承 LoRA Manager 的使用记录。

## 5. 图像种子、采样与后处理

界面中的种子是**图像种子**，允许整数 `0` 到 `1125899906842624`（`2^50`）：

- 随机模式：每张图分别生成图像种子和提示词抽取种子。
- 固定模式：整个批次使用指定图像种子，但每张图仍重新抽取随机池。固定图像种子不等于冻结提示词。
- 随机按钮：抽一个新图像种子并切换到固定模式。

提示词抽取种子由服务保存到历史，普通随机台不提供单独固定它的控件。需要完全冻结已抽取提示词时，使用历史的“原样复现”或“同词变体”。

普通底图使用一段 `KSampler`。双采样器将总步数按切换步分为两段，允许独立设置第二段 CFG、采样器、调度器和中间潜空间调整。两种底图模式分别保留编辑草稿。默认双采样器使用 Sesqui，倍率为 1 时仍使用 Sesqui 节点；切换到普通底图可去除这项依赖。

当前只支持 v4 流程，开启的阶段按以下固定顺序执行：

```text
底图 → 像素高清 → 潜空间放大（含重采样） → 整图后采样
     → 脸部细化 → SeedVR2 → N 卡 VSR → DLSS → 保存
```

未启用的阶段跳过。潜空间放大和整图后采样是独立阶段，同时启用会执行两次重采样。后处理继承底图的主模型、LoRA 和提示词；SeedVR2 使用自己的模型与 VAE。各阶段的节点、模型和实时选项分别检查，仅启用的可选阶段需要对应依赖。

生成期间再次提交会加入队列，任务使用提交时的参数快照。队列条目可取消；停止操作会停止当前批次并清空等待队列。原图逐张保存，已完成的记录仍可在历史查看。

## 6. 历史的四种重生成方式

这些操作从所选历史记录读取设置，不使用当前随机台表单替换历史设置。

| 方式 | 提示词与抽取内容 | 图像种子 | 数量与用途 |
| --- | --- | --- | --- |
| 原样复现 `replay` | 冻结历史最终正向/负向词和当时抽取内容 | 使用历史原种子，提示词种子也保留 | 固定 1 张，按原参数重新执行 |
| 同词变体 `prompt_variant` | 冻结历史最终正向/负向词及内容 | 每张换新图像种子，保留历史提示词种子 | 1–100 张，观察同词不同构图 |
| 局部重抽 `content_redraw` | 只重抽勾选的历史随机维度，其余随机内容按历史恢复 | 每张换新图像种子和提示词种子 | 1–100 张，保留一部分题材 |
| 按原设置重抽 `settings_reroll` | 重新使用历史的池选择、开关、固定词与参数抽取 | 每张换新图像种子和提示词种子 | 1–100 张，继续原配方的随机生成 |

局部重抽只能选择历史中原本使用随机池的维度。无法可靠恢复的维度必须一起重抽；候选池无法产生新组合时会报告原因。原样复现和同词变体使用历史 LoRA 运行快照；按原设置重抽以及重抽人物的局部重抽会使用当前人物绑定。详情中的资源检查会说明操作不可用的原因。

“原样复现”是重新执行原参数与种子，不是复制原图，也不承诺不同模型文件、节点版本或计算环境下逐像素相同。当前仅接收 v4 历史和设置，v2/v3 流程不会自动迁移重跑。

详情中的“载入参数”是另一个操作：将历史模型、LoRA、采样和后处理等参数带回随机台，固定历史图像种子，同时保留当前五池选择、各维度模式/固定词和生成数量。它不会立即提交生成。

## 7. 作品收藏、原图与备份

历史支持查看最终提示词、种子、参数、抽取结果、全尺寸图片和作品收藏。可创建、重命名和排序收藏夹，按收藏夹查看作品，并批量加入或移出收藏夹。作品收藏针对本项目生成记录；不提供外部图片上传、图片反推或单图导入工作台。

原图位于 ComfyUI 的实际输出根目录下：

```text
AnimaRandomWebUI/YYYY-MM-DD/批次ID/image_....png
```

若 ComfyUI 改过输出目录，以它的实际配置为准。WebUI 的“打开所在文件夹”用于定位原图。历史卡片的缩略图是可重建缓存，不能替代原图。

默认数据目录结构：

| 文件或目录 | 内容 |
| --- | --- |
| `history.sqlite3` | 批次、图片记录与作品收藏整理 |
| `favorites.json` | 词条及画师收藏与分组 |
| `custom_prompts.json` | 自定义词条、导入内容和分组 |
| `lora_library.json` | 本地 LoRA 整理、默认权重与人物绑定 |
| `lora_trigger_overrides.json` | 本地 LoRA 触发词覆盖 |
| `prompt_replacements.json` | 规范开关与自定义替换规则 |
| `style_presets.json` | 本地风格/参数预设 |
| `history-thumbnails/` | 历史缩略图缓存 |
| `webui.log`、轮转日志 | 服务运行日志 |

部分文件在首次写入后创建；数据保护可能产生备份或事务文件，备份时包含整个目录。停止 WebUI 后同时备份数据目录和原图目录。默认新建数据，不导入原项目数据库、收藏或旧浏览器草稿。

浏览器表单、主题和视图偏好使用 `anima-random-webui` 前缀，与服务端文件分开。站点地址和端口相同的浏览器标签页共享这些草稿；仅更换 `--data-dir` 不会清空浏览器状态。需要并行维护独立配置时，使用不同端口或独立浏览器配置。

删除作品时可选择“只删除记录，保留原文件”或“永久删除原文件及记录”。后者会实际删除对应原图；删除收藏标记或收藏分组则不等于删除原图。

## 8. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| WebUI 端口占用 | 关闭已有实例，或使用其他 `--port`；更换 WebUI 端口不会改变 ComfyUI 端口 |
| 显示 ComfyUI 连接失败 | 确认本机 ComfyUI 已启动，核对 `--comfy-url` 和监听地址 |
| 模型/LoRA 无法选择 | 查看分类原因；在共享 LoRA Manager 中扫描并确认 `base_model=Anima`，然后刷新分类 |
| 基础词池缺失 | 查看 Anima Tools 路径与缺失文件提示，修正 `--anima-tools-dir` 后重启 |
| 节点缺失或选项无效 | 按 [节点清单](dependencies.md) 检查 ComfyUI `/object_info`；未使用的可选阶段可关闭 |
| 历史原图打不开 | 检查 ComfyUI 输出目录和原文件是否仍在；数据库和缩略图不包含原图备份 |
| 数据只读提示 | 阅读页面原因和 `webui.log`，先保留现有文件与备份，再修复数据问题 |
| 浏览器界面资源不一致 | 刷新页面，确认访问的是当前源码启动的端口 |

开发检查运行 `python scripts/check.py`（使用项目虚拟环境）。该检查不自动进行真实 GPU 生图；具体已验证流程以本次验收报告为准。
