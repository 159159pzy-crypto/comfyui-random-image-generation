# Anima Random Studio

本地 WebUI 使用 `AnimaBasicV7 (3).json` 的模型、LoRA、采样、高清修复和保存链路，逐张调用本机 ComfyUI。角色、服装、姿势、背景和表情均可关闭、从随机池抽取或使用固定提示词。

## 启动

1. 先启动 `F:\comfyui`，确认可以访问 `http://127.0.0.1:8188`。
2. 双击 `启动Anima随机生图WebUI.bat`。
3. 浏览器会打开 `http://127.0.0.1:8190`。

历史索引保存在 `data\history.sqlite3`，图片仍由 ComfyUI 保存到 `output\AnimaRandom\日期\批次编号`。删除 WebUI 历史不会删除图片文件。

派生的可视化工作流位于项目根目录的 `AnimaBasicV7-Random-WebUI.json`，原始工作流副本保存在 `sources` 目录且不会被修改。

## 随机池与自定义项

- 五个随机池均可查看内容、搜索、筛选、收藏、手动选择候选项或全池随机。
- 表情池内置 16 种常用表情，每张图片最多抽取一种表情。
- 在随机池中点击“新建分组”可为当前池创建自定义分组；一个自定义项可同时加入多个分组。
- 自定义分组只管理自定义项，不会改动内置数据。删除分组也不会删除组内条目。

## 批量导入

1. 打开任意随机池，点击“批量导入”。
2. 下载 JSON 或 CSV 模板并填写；一个文件可以同时包含多个随机池的条目。
3. 选择文件后先查看校验结果。新条目默认导入，重名自定义项默认跳过，也可逐项改为覆盖；错误行不会写入。
4. 点击“确认导入”。导入会一次性写入，发生校验错误时不会留下部分数据。

模板字段：

- 必填：`section`、`title`、`prompt`。`section` 可选 `character`、`clothing`、`pose`、`background`、`expression`。
- 可选：`subtitle`、`gender`、`hair`、`eye`、`copyright`、`groups`、`categories`、`traits`。
- CSV 的多值字段使用 `|` 分隔，例如 `常用|可爱`；JSON 中可使用字符串数组。
- 模板中的新分组会随导入自动创建。内置条目不允许被覆盖。

## 收藏画师

在“固定画师”中用逗号分隔多个画师名，点击心形按钮后可收藏当前输入。收藏画师会显示为快捷标签，点击即可追加到固定画师并自动去重；`@name` 和 `by name` 会统一保存为 `name`。
